# 🎨 Canvas Builds

**India's premier digital gifting platform.** Crafting aesthetic, code-driven digital gifts and emotional website templates for birthdays, anniversaries, apologies, and special moments.

---

## ✨ Overview
Canvas Builds bridges the gap between technical architecture and emotional expression. Instead of boring static greeting cards, users can unlock, customize, and share interactive React website templates designed to spark joy.

---

## 🚀 Key Features

* **Curated Template Store:** Explore hand-crafted React templates categorized by occasion (Anniversary, Best Friends, Apologies, Birthdays).
* **Interactive Previews:** Watch live video walkthroughs, preview embedded Spotify playlists, and view custom Google Maps memory pins directly within template cards.
* **Flexible Purchase Paths:**
  * **Ready Website:** Fully customized, deployed, and hosted by our team with a live link and QR code delivered within 24 hours.
  * **Premium Code:** Instant access to clean, modern React & Tailwind source code accompanied by a 5-minute free deployment guide for Vercel or GitHub Pages.
* **Smart AI Assistant ("Adrix"):** Integrated voice and text assistant powered by Gemini models to help users find the perfect template or answer support questions instantly.
* **Secure Admin Command Center:** A role-based access control (RBAC) dashboard enabling live database management, order tracking, subscriber analytics, and direct HTML email replies to customer messages.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, Vite, Tailwind CSS, Framer Motion, React Router
* **Backend & Database:** Supabase (PostgreSQL, Row Level Security, Auth, Edge Functions)
* **Automation & Email:** Node.js, Express, Nodemailer (Automated delivery of HTML gift templates and updates)
* **AI Framework:** Google GenAI / Gemini APIs
